# Portfolio

Nitesh's portfolio presents personal work, open source contributions, and writing.

## Language

**Project**:
A tool, application, or experiment built by Nitesh.
_Avoid_: Product, case study

**OSS contribution**:
A change Nitesh contributed to an existing open source project.
_Avoid_: Personal project, owned project

**Preview**:
A thumbnail that introduces a project or OSS contribution. A placeholder preview is decorative and does not represent a working demo or a measured result.
_Avoid_: Demo, scientific plot

**Write-up**:
A detailed account of a project or OSS contribution.
_Avoid_: Blog post, invented case study

**Blog post**:
A dated piece of writing published independently of a project or OSS contribution.
_Avoid_: Write-up, project page
